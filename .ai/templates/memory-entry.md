# Memory Entry Template

Copy to `.ai/memory/<topic>/NNN-<kebab-title>.md` (next free number in that
topic folder). Entries are self-contained — a reader with only this file must
understand the decision, why it was made, and what it changed.

```md
# NNN — <Title>

- **Date:** YYYY-MM-DD
- **Topic:** <module or area>
- **RFC:** <link, if one exists>

## Context

_What prompted this decision._

## Decision

_What was decided, precisely._

## Rationale

_Why this over the alternatives._

## Consequences

_What changed, what to watch out for._
```
