# Reporting Security Issues

If you believe you have found a security vulnerability in this repository, we
encourage you to let us know right away. We will investigate all legitimate
reports and do our best to quickly fix the problem.

## How to let us know

Open an issue:

<https://github.com/mimshins/sudo-overclock/issues/new>

For sensitive reports, avoid posting exploit details publicly — describe the
issue and request a private channel instead.
